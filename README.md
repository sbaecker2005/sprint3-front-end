# Sabarah Flow

## Overview
Sabarah Flow is a web-based application designed to enhance the pediatric healthcare experience by streamlining the process of patient triage and management. By leveraging technology, Sabarah Flow aims to reduce wait times, improve communication between families and healthcare providers, and ensure that children receive timely and appropriate care.

## Features
- **Pré Check-in**: Allows parents to input symptoms before arriving at the hospital, optimizing the triage process.
- **Classificação Automática**: An intelligent algorithm assesses the severity of symptoms in real-time.
- **Organização da Fila**: Patients with higher risk are prioritized for medical attention.
- **Segurança dos Dados**: All information is securely stored and complies with LGPD regulations to protect family privacy.
- **User-Friendly Interface**: Designed for ease of use by both parents and healthcare professionals.

## Pages
- **Home**: Introduction to Sabarah Flow and its benefits.
- **Como Funciona**: Detailed explanation of how the system operates in three simple steps.
- **Benefícios**: Overview of the advantages for parents, hospitals, and children.
- **Sobre Nós**: Information about the Sabarah Flow team, mission, vision, and values.
- **Contato**: Contact form for inquiries and further information.

## Getting Started
To run the Sabarah Flow project locally, follow these steps:

1. **Clone the Repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the Project Directory**:
   ```
   cd sabarah-flow
   ```

3. **Open the HTML Files**: You can open the HTML files in your preferred web browser to view the application.

## Assets
- **Images**: All images used in the project are located in the `assets/img` directory.
- **Styles**: Custom styles for the project are defined in `assets/css/custom.css`.
