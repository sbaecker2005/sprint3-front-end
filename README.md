# Sabarah Flow

Sabarah Flow é um projeto desenvolvido para transformar a experiência de atendimento em hospitais pediátricos, unindo tecnologia, empatia e segurança.

A plataforma foi pensada para permitir que pais realizem o pré check-in antes mesmo de chegarem ao hospital, informando os sintomas da criança por meio de um site ou aplicativo. Um algoritmo inteligente analisa os dados recebidos e classifica automaticamente os casos de acordo com a gravidade, permitindo que a fila de atendimento seja organizada de forma mais eficiente e justa.

Além de melhorar o tempo de resposta para os casos críticos, o Sabarah Flow também reduz o estresse dos responsáveis, melhora o fluxo hospitalar e garante mais transparência e agilidade no atendimento.

Todas as informações são armazenadas com segurança, respeitando as normas da LGPD. O projeto também valoriza a comunicação clara com os usuários, incluindo seções institucionais que apresentam a missão, visão, valores e formas de contato.

Este projeto foi criado com foco em acessibilidade, leveza e aplicação prática em instituições de saúde que buscam inovação no cuidado infantil.
